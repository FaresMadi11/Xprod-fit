# UI/UX Skills Auto-Activation Rule

Whenever the task involves **any frontend or UI work** including HTML, CSS, PHP views, design, layout, components, animations, colors, typography, mobile responsiveness, or user experience, you MUST consult the relevant installed UI/UX skills before writing any code.

## Skills disponibles (consultar antes de hacer cambios de UI/UX):

| Skill | Cuando usarla |
|-------|--------------|
| `ui-ux-pro-max` | Diseno general, decisiones visuales, UX, accesibilidad, interaccion, responsive, tipografia, color, animaciones, formularios |
| `design` | Sistemas de diseno, decisiones de paleta, tokens, jerarquia visual |
| `design-system` | Componentes reutilizables, tokens de diseno, guias de estilo |
| `ui-styling` | CSS avanzado, estilos de componentes, micro-interacciones |
| `brand` | Identidad de marca, consistencia visual |
| `banner-design` | Banners, headers, secciones hero |
| `slides` | Presentaciones, layouts de contenido |

## Instrucciones estrictas:

1. **Siempre** leer ui-ux-pro-max SKILL.md antes de disenar o refactorizar cualquier componente de UI.
2. Aplicar las 10 categorias de reglas por prioridad: Accessibility > Touch > Performance > Style > Layout > Typography > Animation > Forms > Navigation.
3. Nunca hacer un componente minimo viable - aplicar siempre los principios premium de la skill.
4. El estandar minimo de toque es 44x44px en movil.
5. Contraste de texto minimo 4.5:1 (WCAG AA).
